# Python_assigment_3

📌 About This Repository

This repository contains a collection of beginner-level Python programs developed as part of my Python Fundamentals learning journey.

The projects focus on understanding basic Python concepts such as user input, variables, conditional statements, loops, exception handling, and mathematical operations.

🚀 Projects Included

1. Number Guessing Game 🎯

A simple interactive game where the user needs to guess a randomly generated number between 1 and 10.

Features:

Generates a random number.

Allows up to 3 valid attempts.

Provides hints such as "Too High" and "Too Low".

Handles invalid inputs.

Displays a winning or losing message.

Concepts Used: random, while loop, if-elif-else, try-except, user input.

2. Multiplication Table Generator ✖️

A Python program that accepts a number from the user and generates its multiplication table from 1 to 10.

Features:

Accepts user input.

Generates multiplication tables automatically.

Displays results using formatted strings.

Concepts Used: Variables, while loop, arithmetic operators, f-strings.

3. BMI Calculator ⚖️

A basic Body Mass Index (BMI) calculator that calculates BMI using the user's weight and height.

Formula:

BMI = Weight (kg) / Height (m)²

Features:

Accepts weight in kilograms.

Accepts height in meters.

Calculates BMI using the standard formula.

Concepts Used: Variables, user input, type conversion, arithmetic operators.
